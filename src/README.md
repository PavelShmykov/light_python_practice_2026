# Индексатор папок

Консольная утилита для сканирования папок с хранением индекса в SQLite.

## Запуск


python main.py <folder_path> <backup_folder> [--skip-ext .tmp .log .sys] [--demo-db]


### Аргументы

| Аргумент | Описание |
|---|---|
| `folder_path` | Путь к папке для сканирования |
| `backup_folder` | Путь к папке с резервной копией |
| `--skip-ext` | Расширения для пропуска (по умолчанию: `.tmp .log .sys .md`) |
| `--demo-db` | Выполнить демонстрацию операций с базой данных |


## Структура

- `main.py` — точка входа
- `db_sqlite3.py` — работа с базой данных
- `scanner.py` — рекурсивный обход папки
- `filter.py` — фильтрация файлов по расширению
- `hasher.py` — подсчёт md5 хэша файла
- `backup.py` — сравнение папки с резервной копией
- `data/app.db` — файл базы данных (создаётся автоматически)

## Таблицы БД

- `files` — индекс найденных файлов (путь, размер, дата, расширение, хэш, статус)
- `scan_runs` — история запусков (папка, дата и время запуска)
- `backup_checks` — история проверок бэкапа (дата, статус, путь к файлу)

## Фильтрация

По умолчанию пропускаются файлы с расширениями `.tmp`, `.log`, `.sys`, `.md`.

Список расширений задаётся при запуске через `--skip-ext`.

## Дубликаты

Программа считает md5 хэш каждого файла и находит файлы с одинаковым содержимым.

## Резервная копия

Программа сравнивает исходную папку с бэкапом и показывает три категории различий:
- `missing` — файлы которые есть в исходной папке но нет в бэкапе
- `extra` — файлы которые есть в бэкапе но нет в исходной папке
- `changed` — файлы которые есть в обоих местах но отличаются по размеру или хэшу

Результат каждой проверки сохраняется в БД.
